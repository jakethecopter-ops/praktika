## Структура и соответствие заданиям

| Папка | Задание | Содержимое |
|---|---|---|
| `1-4work_prakitka/` | Задания 1–4 (базовый C#) | Кодстайл, типы данных, ООП, коллекции, делегаты и события |
| `StoreAnalytics/` | «LINQ» | Консольное приложение «Аналитика интернет-магазина» |
| `BookingSystem/` | «Unit-тестирование» | Сервис бронирования и тесты MSTest |
| `BookStoreDB/` | «Базы данных» | SQL-скрипты: таблицы, связи, индексы, запросы |
| `DatabaseWorkDemo/` | «Работа с БД из кода» | CRUD через ADO.NET и Entity Framework Core (SQLite) |
| `DatabaseWorkDemo/WorkoutTracker.Api/` | Итоговое задание (backend) | REST API учёта тренировок (ASP.NET Web API) |
| `workout-frontend/` | Итоговое задание (frontend) | Веб-интерфейс на Vue.js |
| `screenshots Workout/` | Итоговое задание (скриншоты) | Скриншоты запросов из Postman и Swagger |

Каждый проект находится в отдельной папке.
